# CLAUDE.md

Правила работы над этим репозиторием. Полная версия для людей: [CONTRIBUTING.md](CONTRIBUTING.md).

## Проект

Приватный проект на Python 3.12, пакет `femevmen` в макете `src/`.
Менеджер зависимостей — `uv`, линтер и форматтер — `ruff`, тесты — `pytest`.

## Команды

```bash
uv sync                    # установить зависимости
uv run pytest              # тесты
uv run pytest tests/test_smoke.py::test_package_exposes_version  # один тест
uv run ruff check .        # линтер
uv run ruff format .       # форматирование
```

## Процесс

- Никогда не коммитить напрямую в `main`. Сначала ветка: `git switch -c feat/<имя>`.
- Префиксы веток: `feat/`, `fix/`, `refactor/`, `docs/`, `chore/`.
- Коммиты в формате Conventional Commits: `feat(scope): описание`.
- Перед созданием PR прогнать линтер и тесты локально.
- PR создаётся через `gh pr create`, шаблон заполняется целиком.
- Слияние squash, только при зелёном CI.

## Код

- Длина строки 100, target `py312`.
- Аннотации типов на публичных функциях.
- Новое поведение закрывается тестом в `tests/`.
- Секреты только через переменные окружения. Никаких токенов в коде и коммитах.

## Чего не делать

- Не пушить в `main` и не сливать PR с красным CI.
- Не отключать проверки ради прохождения сборки.
- Не добавлять зависимость без явной необходимости, сначала обсудить.
- Не коммитить и не пушить без явной просьбы.
