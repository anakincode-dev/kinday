# CLAUDE.md

Правила работы над этим репозиторием. Полная версия для людей: [CONTRIBUTING.md](CONTRIBUTING.md).
Спецификация: [SPEC.md](SPEC.md). План реализации: [PLAN.md](PLAN.md).

## Проект

Telegram-бот семейных напоминаний, пакет `kinday` в src-layout. Python 3.12+,
`uv` для зависимостей (только `uv add`, никогда `pip`), `ruff` — линт и формат,
`pytest` — тесты, `ty` — типы.

## Команды

```bash
uv sync
uv run pytest
uv run ruff check . && uv run ruff format .
uv run ty check
```

## Главное правило архитектуры

`core/` — чистый Python, не импортирует `aiogram`, `apscheduler`, `sqlite3`,
`kinday.storage`, `kinday.scheduler`, `kinday.telegram`. Проверяется
`tests/test_core_boundary.py`. Ядро объявляет протоколы (`core/ports.py`),
внешние слои их реализуют и передают в ядро снаружи.

## Ключевые решения из SPEC.md

- Родство: хранятся только `parent_of` и `spouse_of`, остальное выводится
  обходом графа (глубина ≤ 3). Неизвестный родитель — скрытая заглушка,
  первый настоящий родитель сливается с ней.
- `reminders` — источник истины, отправка в три шага: claim → send → mark.
- Настройки напоминаний (пояс, смещения, время) принадлежат аккаунту, а не
  семье, и действуют во всех его семьях сразу.
- 29 февраля в невисокосный год → напоминание 28 февраля.

## Процесс

Ветка от `main` (`feat/`, `fix/`, `refactor/`, `docs/`, `chore/`), Conventional
Commits, `gh pr create` с шаблоном, squash-слияние только при зелёном CI.
Новое поведение закрывается тестом. Секреты — только через переменные
окружения, в репозиторий не попадают.
